Polish word list
================

Source:
https://github.com/MaciekTalaska/diceware-pl

Original author:
Maciek Talaska

The word list is distributed under the MIT License.

The list is based on an earlier Polish Diceware list
created by Piotr "DrFugazi" Tarnowski and was substantially
modified by Maciek Talaska.

This project converts the source word list to JSON and uses
it for human-readable password generation.
