## Reproduction

Install `requirements-dev.txt` into an isolated environment; activate it before
running the Python command. Ruff was run separately without changing dependency
pins. Local logs and tooling are under ignored `build/v140-*` paths.

```bash
QT_QPA_PLATFORM=offscreen QT_QPA_PLATFORMTHEME= python -m pytest
git diff --check
./android/gradlew -p android testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

Use a configured JDK/Android SDK. Local Gradle used JDK 21, Gradle 8.9, two
workers and Kotlin compilation in-process. Instrumentation used the built debug
and test APKs, installed on the task-owned API-35 emulator, followed by:

```bash
adb -s emulator-5590 shell am instrument -w \
  pl.franek.passwordgenerator.test/androidx.test.runner.AndroidJUnitRunner
```

The terminal log ends with `OK (19 tests)`; the screenshot-only rerun ends with
`OK (1 test)`. Public screenshots are generated by
the desktop preview script and the Android capture test linked in the gallery.
Existing released screenshots were preserved.
