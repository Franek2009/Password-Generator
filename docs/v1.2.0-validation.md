| TalkBack oraz czytnik desktopowy | Czytelne etykiety, logiczna nawigacja, odczyt oryginału i dostępne kopiowanie | Niewykonane |
| Długi wynik, przepisywanie, schowek, wąski ekran/duża czcionka | Całość dostępna, schowek bez wizualnych odstępów; frazy zachowują separatory | Do potwierdzenia ręcznie |
| Presety wbudowane i własne | Poprawne kontrolki, niezależność trybów, trwałość po restarcie, ochrona wbudowanych przed usunięciem | Do potwierdzenia ręcznie |
| CI kodu `e1c3966` | Python, Linux/Windows, Android i osobny workflow Android UI zielone | Zaliczone; buildy z taga sprawdzają ponownie wersję wydania |

Cofnięcie dostępu do URI musi dotyczyć wcześniej skutecznie odczytanego dokumentu
z rzeczywistym trwałym grantem. Usunięcie pliku, nieistniejący URI albo odmowa
odczytu kontaktów nie dowodzą tego scenariusza. Jeśli urządzenie nie daje sposobu
cofnięcia takiego grantu, pozostaw tę pozycję otwartą do kontrolowanego testu
`releasePersistableUriPermission` w kontekście aplikacji. Zwykłe uprawnienia
aplikacji do plików nie muszą odpowiadać grantowi selektora dokumentów.

## Uruchamianie automatycznych sprawdzeń

```bash
QT_QPA_PLATFORM=offscreen QT_QPA_PLATFORMTHEME= python -m pytest
git diff --check
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

Dla emulatora testowego z katalogu głównego:

```bash
ANDROID_SERIAL=emulator-5554 bash scripts/android_ui_checks.sh
```

Skrypt zmienia ustawienia animacji emulatora; na prywatnym telefonie użyj
kontrolowanego uruchomienia instrumentacji i zachowaj/przywróć ustawienia
systemowe (w tym skalę czcionki przy teście zrzutów). Testy modyfikują konfigurację
aplikacji i jej własne presety — nie wykonuj ich na instalacji z ważnymi danymi.

Push nie publikuje wydania. Workflow Android UI uruchamia się dla PR lub ręcznie,
nie od samego push na `master`. Po weryfikacji wyników i usunięciu ewentualnych
błędów można osobno zatwierdzić tag i publikację v1.2.0. Nie ustawiaj tej wersji
ręcznie w metadanych aplikacji.
